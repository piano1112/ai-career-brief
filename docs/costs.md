## 2. LLM (Claude API)

단가 (100만 토큰당): Opus 5.5 입력 $4 / 출력 $20 / 캐시 읽기 $0.20 · Sonnet 5.5 $2 / $10 · Haiku 5.5 $0.10 / $0.50. Batches API는 50% 할인.

### 대화 에이전트 (Opus 5.5) — 월 약 $15~60

가정: 하루 20턴, 한 턴에 API 호출 2번(도구 호출 포함). 호출 1번당 입력 8K 토큰(시스템 프롬프트 + user_fact + 도구 정의 + 대화 기록, 80%는 캐시 적중), 출력 800 토큰(thinking 포함).

- 호출 1번: 입력 1.6K×$4 + 캐시 6.4K×$0.2 + 출력 0.8K×$20 ≈ $0.024
- 하루: 40번 ≈ $1 → **월 ~$30** (사용량에 따라 $15~60)

### 백그라운드 분석 (M5) — 모델 선택에 따라 월 $2~60

가정: 하루 새 항목 40개(동향 + 공고) × (입력 3K + 출력 400), 채용 포털 9곳 LLM 추출 × (입력 20K + 출력 2K), 브리핑 초안 1회(입력 20K + 출력 3K).

| 모델 | 일 | 월 | Batches(50%) 적용 시 월 |
|---|---|---|---|
| Opus 5.5 | ~$2.0 | ~$60 | ~$30 |
| Sonnet 5.5 | ~$1.0 | ~$30 | ~$15 |
| Haiku 5.5 | ~$0.05 | ~$1.5 | ~$1 |

- 가장 큰 비중은 **포털 페이지 LLM 추출**이다 → 페이지 내용의 해시가 바뀌었을 때만 추출하면 대부분 사라진다 (공고가 매일 바뀌지 않으므로).
- 품질 차이는 실제 데이터로 비교한 뒤 정한다 (decisions 008).
